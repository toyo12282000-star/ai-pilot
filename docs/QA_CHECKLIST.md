## 既知の残課題（MVP Preview）

- 利用規約 / プライバシーは正式法務文書ではない
- ゲストモードはセッション内のみ（再起動でログイン画面へ）
- OAuth（Google / Apple）は Web / 実機で個別確認が必要
- `SUPABASE_URL` 設定誤り時は通信エラー（`.env` 要確認）
